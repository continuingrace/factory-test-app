# RE WEBAPP STANDARD

- Pretendard
- Mobile First + Desktop responsive
- Minimal / Simple / Modern
- Clear typography hierarchy
- Deliberate letter-spacing, line-height, margins and padding
- Visible version number in UI
- LocalStorage autosave as the default for ordinary local state
- PWA baseline
- User data is local-first unless explicitly requested otherwise
- Preserve unrelated working features
- Prefer minimal changes over broad refactors
- Run QA before committing important changes
